# 02 — 从来源批准第一条规范记忆

**What to build:** 创作者可以提交一份本地来源，审阅一个最小整合提案，并在批准后得到第一条带来源的规范记忆、知识字典入口和主知识胶囊记录。

**Blocked by:** 01 — 初始化并检查 V2 实例.

**Status:** ready-for-agent

- [ ] 来源拥有稳定身份、版本、内容哈希和最低来源凭证。
- [ ] 提交只创建待审整合提案，不直接修改规范记忆。
- [ ] 批准后原子生成稳定 `memory_id`、当前版本、名称入口和唯一主胶囊记录。
- [ ] 规范正文符合正文预算，超出内容留在证据层。
- [ ] 重复批准通过幂等键返回同一结果，并记录紧凑审计事件。
