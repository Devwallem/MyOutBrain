# 13 — 迁移经审计的知识闭包

**What to build:** 创作者可以选择新增知识，审计其完整来源与知识依赖闭包，手动生成增量 ZIP，并在另一实例预览和幂等导入。

**Blocked by:** 05 — 复用重复来源并通过别名消歧; 06 — 修订、历史化、停用与永久删除知识; 07 — 完成统一审阅提案与批次决定.

**Status:** ready-for-agent

- [ ] 导出计算选中知识的传递证据与知识依赖闭包。
- [ ] 任一依赖受限、缺失或无法审计时阻止整个导出并报告路径。
- [ ] 普通 ZIP 包含版本清单、稳定身份、对象、关系和迁移检查点，不复制 SQLite 内部布局。
- [ ] 目标导入前完成 dry-run、哈希与版本检查。
- [ ] 同一包重复导入不产生重复对象、关系或知识版本。
- [ ] 目标知识冲突只进入统一审阅提案，不自动覆盖。
