# 05 — 复用重复来源并通过别名消歧

**What to build:** 创作者重复提交相同来源、相同知识、新来源支持或重名知识时，系统复用正文和身份，保留新增关系，并通过别名与分区候选安全消歧。

**Blocked by:** 03 — 召回知识并查看召回日志.

**Status:** resolved

- [x] 相同内容和相同来源是无操作，不产生新对象、版本或提案。
- [x] 相同知识由新来源支持时只合并去重来源关系。
- [x] 近似但语义范围不同的内容形成补充、修订或冲突提案。
- [x] 改名后旧名成为无循环重定向别名。
- [x] 同名不同领域知识返回带分区摘要的候选集合，不静默任选或自动合并。
- [x] 所有精确与重名路径均可通过召回黑盒验证。

## Answer

CLI 与领域公开接缝现会复用精确重复知识和待审提案：同来源重复提交保持领域状态不变，新来源只补来源与 `supports` 关系；近似内容按语义范围形成补充、修订或冲突提案。改名将旧名直接指向稳定知识身份，同名异域召回返回带分区摘要的候选集合。

冲突提案在工单 05 中是完整、可审阅、可拒绝或延期的冲突分组；批准及批准后物化明确留给工单 09。当前公开审阅入口不会把冲突批准报告为成功，也不会改变召回结果。
