# 05 — 复用重复来源并通过别名消歧

**What to build:** 创作者重复提交相同来源、相同知识、新来源支持或重名知识时，系统复用正文和身份，保留新增关系，并通过别名与分区候选安全消歧。

**Blocked by:** 03 — 召回知识并查看召回日志.

**Status:** ready-for-agent

- [ ] 相同内容和相同来源是无操作，不产生新对象、版本或提案。
- [ ] 相同知识由新来源支持时只合并去重来源关系。
- [ ] 近似但语义范围不同的内容形成补充、修订或冲突提案。
- [ ] 改名后旧名成为无循环重定向别名。
- [ ] 同名不同领域知识返回带分区摘要的候选集合，不静默任选或自动合并。
- [ ] 所有精确与重名路径均可通过召回黑盒验证。
