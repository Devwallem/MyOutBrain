# 11 — 安装三种入口并协商协议能力

**What to build:** 创作者可以为 Codex、OpenCode 和 Claude Code 安装可替换入口，三者通过同一 MCP/CLI 领域契约使用同一个主私人实例，并在写入前协商版本与能力。

**Blocked by:** 03 — 召回知识并查看召回日志; 07 — 完成统一审阅提案与批次决定.

**Status:** ready-for-agent

- [ ] MCP 与 CLI 对相同请求产生同构领域响应和稳定错误类别。
- [ ] 三种入口可以幂等安装、重装、检查和卸载。
- [ ] 入口目录不保存规范数据，卸载不修改私人实例。
- [ ] 主版本不兼容时拒绝语义写入，旧次版本可以兼容读取。
- [ ] 入口无法理解提案效果时不能批准，并且不得旁路访问 SQLite。
- [ ] 写操作使用幂等键和 `expected_version` 进行并发保护。
