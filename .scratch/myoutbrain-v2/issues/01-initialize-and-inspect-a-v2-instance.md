# 01 — 初始化并检查 V2 实例

**What to build:** 创作者可以初始化一个干净的 V2 主私人实例，并通过最高层命令确认 Schema、规范存储、对象存储和单写者状态均可用。

**Blocked by:** None — can start immediately.

**Status:** claimed

- [ ] 首次初始化建立带版本的 SQLite 规范状态和内容寻址对象存储。
- [ ] 重复初始化保持幂等，不覆盖已存在数据或隐式迁移 V1 语义内容。
- [ ] 状态命令通过稳定领域响应报告实例版本、写入可用性和完整性摘要。
- [ ] 并发写入只允许一个写者，失败拥有稳定错误类别。
- [ ] 黑盒测试证明中断写入只留下旧完整状态或新完整状态。
