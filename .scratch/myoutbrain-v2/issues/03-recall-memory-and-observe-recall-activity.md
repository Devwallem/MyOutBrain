# 03 — 召回知识并查看召回日志

**What to build:** 创作者可以提出一个由已批准知识回答的问题，得到紧凑召回结果、按需证据展开和可回答性结论，并在活动视图中看到本次知识召回。

**Blocked by:** 02 — 从来源批准第一条规范记忆.

**Status:** resolved

- [x] 知识字典、分区树、局部 FTS 和受限全库 FTS 共同产生候选。
- [x] 第一阶段召回包遵守默认字节预算，只带证据状态和稳定引用。
- [x] 同一 `recall_id` 可以幂等展开指定证据摘录并使用独立预算。
- [x] 能力引擎返回结构化二元可回答性，本地核心执行硬冲突约束。
- [x] 知识库来源声明元数据足以让入口默认只呈现结论并在追问时解释证据。
- [x] 每次召回写入不复制问题、知识正文或答案的紧凑召回日志。
- [x] 无 Embedding、无网络时全部验收通过。

## Answer

工单 03 tracer bullet 已通过 `MemoryGateway`、CLI JSON 和真实临时 SQLite 黑盒接缝交付。V2 基础召回以字典、最小分区树、局部 FTS 和固定上限全库 FTS 合并候选；完整第一阶段包按确定性紧凑 JSON 计入默认 16 KiB 预算。能力引擎在收到召回材料后返回二元判断，本地核心执行无候选与未决冲突硬约束；同一 `recall_id` 可按稳定证据句柄展开本地摘录并重新提交判断。活动视图只保存稳定任务标识、路径、记忆身份/版本、预算、展开和可回答性信号。
