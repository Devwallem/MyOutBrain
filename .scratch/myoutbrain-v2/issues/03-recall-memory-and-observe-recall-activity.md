# 03 — 召回知识并查看召回日志

**What to build:** 创作者可以提出一个由已批准知识回答的问题，得到紧凑召回结果、按需证据展开和可回答性结论，并在活动视图中看到本次知识召回。

**Blocked by:** 02 — 从来源批准第一条规范记忆.

**Status:** claimed

- [ ] 知识字典、分区树、局部 FTS 和受限全库 FTS 共同产生候选。
- [ ] 第一阶段召回包遵守默认字节预算，只带证据状态和稳定引用。
- [ ] 同一 `recall_id` 可以幂等展开指定证据摘录并使用独立预算。
- [ ] 能力引擎返回结构化二元可回答性，本地核心执行硬冲突约束。
- [ ] 知识库来源声明元数据足以让入口默认只呈现结论并在追问时解释证据。
- [ ] 每次召回写入不复制问题、知识正文或答案的紧凑召回日志。
- [ ] 无 Embedding、无网络时全部验收通过。
