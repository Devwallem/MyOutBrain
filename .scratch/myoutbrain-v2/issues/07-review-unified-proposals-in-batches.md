# 07 — 完成统一审阅提案与批次决定

**What to build:** 创作者可以在一个队列中审阅派生、整合、归档和研究提案，修改或决定独立项与依赖组，并由本地核心按意图安全物化结果。

**Blocked by:** 02 — 从来源批准第一条规范记忆.

**Status:** claimed

- [ ] 提案完整表达意图、形成方式、优先级、执行效果、证据、盲区、冲突和版本预期。
- [ ] 精确重复自动合并来源，近似项与矛盾项只分组而不静默融合。
- [ ] 支持修改批准、拒绝、延期和按意图物化。
- [ ] 个人认知只能逐项明确确认，不能通过批准整个批次建立。
- [ ] 独立项可以幂等部分成功，依赖组必须原子应用。
- [ ] 失败项回到可重试待审状态，不产生半完成语义。
- [ ] routine 提案按策略压缩，priority、blocking 和明确延期项不普通过期。
