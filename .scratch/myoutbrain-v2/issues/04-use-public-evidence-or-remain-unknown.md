# 04 — 知识不足时补充公开证据或保持未知

**What to build:** 当内部知识不足时，创作者可以允许当前任务进行脱敏公开检索；系统综合允许的公开证据重新判断，仍不足时明确保持未知，并且不把检索结果自动写入知识库。

**Blocked by:** 03 — 召回知识并查看召回日志.

**Status:** resolved

- [x] 内部可回答性失败后才进入当前任务允许范围内的公开检索。
- [x] 外部查询不包含未授权的私人正文或不可见历史。
- [x] 混合回答带有“综合知识库与公开信息”的来源声明语义。
- [x] 公开证据与历史可信知识作为备选材料参与判断，但不自动取代当前知识。
- [x] 公开检索仍不足时只返回已核验内容、关键未知和验证方向。
- [x] 外部结果只可形成审阅提案或研究线索，不能直接物化规范记忆。

## Answer

新增 V2 `search-public` CLI/领域接缝：只有同一任务的内部可回答性已经失败且当前调用显式授权时，才由可信本地脱敏器生成公开安全查询并调用公开来源。公开证据与召回材料共同送入能力层复判；核心仍强制执行无来源、内部或公开冲突等未知门槛，并按实际证据组合声明 MyOutBrain、公开或混合来源。

公开结果保持 `external-unintegrated`，不会自动创建提案、审阅项或规范记忆。仍不可回答时，响应只呈现能力层明确选出的已核验事实、关键未知与验证方向；缺少可信脱敏结果时在外部请求前默认拒绝。
