# 04 — 知识不足时补充公开证据或保持未知

**What to build:** 当内部知识不足时，创作者可以允许当前任务进行脱敏公开检索；系统综合允许的公开证据重新判断，仍不足时明确保持未知，并且不把检索结果自动写入知识库。

**Blocked by:** 03 — 召回知识并查看召回日志.

**Status:** ready-for-agent

- [ ] 内部可回答性失败后才进入当前任务允许范围内的公开检索。
- [ ] 外部查询不包含未授权的私人正文或不可见历史。
- [ ] 混合回答带有“综合知识库与公开信息”的来源声明语义。
- [ ] 公开证据与历史可信知识作为备选材料参与判断，但不自动取代当前知识。
- [ ] 公开检索仍不足时只返回已核验内容、关键未知和验证方向。
- [ ] 外部结果只可形成审阅提案或研究线索，不能直接物化规范记忆。
