# 14 — 整库备份、诊断与垃圾回收

**What to build:** 创作者可以把整个实例压缩为可恢复冷快照，诊断并重建可重建投影，以及在明确预览后删除真正孤立的来源对象。

**Blocked by:** 06 — 修订、历史化、停用与永久删除知识; 10 — 无损裂分与合并知识胶囊.

**Status:** resolved

- [x] 压缩失败安全恢复写入，不生成增量、自动轮换或隐式加密机制。

## Answer

已通过 V2.3 MemoryGateway 与 CLI 领域契约交付实例维护 tracer bullet。整库备份在单写者维护锁内恢复未完成事务、checkpoint 并关闭 SQLite，随后生成实例目录的冷全量 ZIP；失败会清理临时产物并释放写锁，不包含增量、轮换或隐式加密。恢复只解压到新的暂存目录，经过只读 Doctor 后才原子切换为目标目录。

Doctor 校验实例配置、SQLite/schema/FK、来源对象与记录清单哈希、胶囊/叶分区约束、知识依赖闭包终点、协议/入口契约及已物化投影。规范损坏进入受限只读并阻止所有规范写入；显式 repair 仅从规范状态重建 FTS、证据关系图和树摘要。GC 预览计算历史生命周期、经验、审阅、审计、迁移和对象清单引用闭包；只有精确确认后才删除真正孤立对象，并保留不含正文的最小删除标记以阻止静默恢复。
