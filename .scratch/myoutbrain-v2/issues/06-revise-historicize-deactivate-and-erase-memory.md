# 06 — 修订、历史化、停用与永久删除知识

**What to build:** 创作者可以在稳定身份下修订知识、将其标记为历史可信、可恢复停用或明确永久删除，并始终看到旧版本、原因和影响闭包。

**Blocked by:** 03 — 召回知识并查看召回日志.

**Status:** resolved

- [x] 生命周期只允许规范定义的显式状态迁移，时间和召回频率不能自动迁移状态。
- [x] 修订与取代保留旧版本、原因和来源关系。
- [x] 历史可信知识继续可召回并带正确状态。
- [x] 停用退出普通召回但可明确恢复到先前状态。
- [x] 永久删除先展示来源、派生、依赖和备份影响闭包，再要求明确确认。
- [x] 删除留下不含正文的最小标记并阻止旧缓存或迁移静默恢复。

## Answer

已完成显式生命周期迁移、历史可信召回、修订与取代历史、可恢复停用及永久删除 tracer bullet。永久删除会先计算来源、派生、依赖、统一提案、召回与备份影响闭包，并要求明确确认；执行后清除正文与可重建投影，只保留不含正文的最小墓碑，所有重物化入口均拒绝静默恢复已删除身份。

生命周期实现与后续审查修复已集成到当前分支；本轮工单 09/10/12/13 集成后的仓库级验证为严格 mypy 79 个源文件零问题、完整测试 270 项全部通过。
