# 06 — 修订、历史化、停用与永久删除知识

**What to build:** 创作者可以在稳定身份下修订知识、将其标记为历史可信、可恢复停用或明确永久删除，并始终看到旧版本、原因和影响闭包。

**Blocked by:** 03 — 召回知识并查看召回日志.

**Status:** ready-for-agent

- [ ] 生命周期只允许规范定义的显式状态迁移，时间和召回频率不能自动迁移状态。
- [ ] 修订与取代保留旧版本、原因和来源关系。
- [ ] 历史可信知识继续可召回并带正确状态。
- [ ] 停用退出普通召回但可明确恢复到先前状态。
- [ ] 永久删除先展示来源、派生、依赖和备份影响闭包，再要求明确确认。
- [ ] 删除留下不含正文的最小标记并阻止旧缓存或迁移静默恢复。
