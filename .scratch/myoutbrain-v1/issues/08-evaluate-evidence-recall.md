# 08 — 建立证据召回评测

**What to build:** 让单一创作者可以运行一套小型、可重复的证据召回评测，单独判断系统是否选中了正确材料，并以真实失败决定未来是否需要嵌入、重排或其他 RAG 能力。

**Blocked by:** 06 — 显式晋升个人认知

**Status:** ready-for-agent

- [ ] 评测数据能够表达问题、预期来源、是否可回答以及案例类别
- [ ] 基线评测至少覆盖可回答、不可回答、观点冲突和已被取代认知四类案例
- [ ] 评测把证据选择结果与最终回答文风分开报告，模型猜对不能掩盖错误召回
- [ ] 报告清楚列出正确命中、关键遗漏、错误引用和应拒答却回答的案例
- [ ] 评测可以重复运行并产出适合人阅读和后续自动比较的结果
- [ ] 默认评测不依赖实时云端模型，避免模型波动掩盖检索变化
- [ ] 当前无嵌入基线得到明确记录，后续只有观察到持续召回失败时才引入更复杂检索
- [ ] 增加未来检索适配器时可以复用同一评测集进行前后对比，而无需重写问题定义
