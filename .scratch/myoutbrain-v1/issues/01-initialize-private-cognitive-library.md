# 01 — 初始化私人认知库

**What to build:** 让单一创作者可以通过 `myoutbrain init` 安全初始化一个本地私人认知库，明确永久知识、永久机器数据和可重建运行数据的生命周期，并在当前 Windows 主设备上获得可操作的环境诊断。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 首次初始化通过 CLI 建立完整且可识别的知识库结构，并以成功退出状态结束
- [x] 重复初始化保持幂等，不覆盖或清空任何已有内容
- [x] 遇到与预期结构冲突的已有内容时，命令给出明确错误且不留下部分初始化状态
- [x] 初始化明确区分必须备份的永久数据与可删除重建的运行数据
- [x] 初始化配置 Git 排除行为，使原始对象和运行数据不会被普通 Git 跟踪，而知识 Markdown、配置和轻量永久记录仍可进入私有历史
- [x] 初始化检查 Obsidian CLI 是否可用；不可用时给出 Windows 上更新、启用和注册 CLI 的可操作提示，但不损坏已完成的本地初始化
- [x] 初始化建立单写入者锁与原子写入所需的基本约束，并为锁冲突返回稳定错误类别
- [x] 验收测试只通过 CLI 退出状态、输出和外部可观察结果验证行为，不依赖内部模块结构

## Answer

已实现可安装的 `myoutbrain init` CLI：它会建立单根目录知识库结构、写入生命周期配置、维护 Git 排除规则、验证已有配置、保护单写入者并以原子方式提交文件；缺少 Obsidian CLI 时初始化仍成功并提供 Windows 配置指引。实现由 9 个 CLI 验收场景覆盖，并通过严格 mypy、Python 编译检查和当前项目上的真实初始化验证。
