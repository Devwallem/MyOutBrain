# 03 — 基于证据包回答材料问题

**What to build:** 让单一创作者可以通过 `ask` 对已采集的 Markdown 提问，获得以最小证据包为依据、可回到原始材料核验的回答，同时严格执行云端授权、敏感级别和外发审计。

**Blocked by:** 02 — 幂等采集 Markdown 原始材料

**Status:** ready-for-agent

- [ ] `ask` 能针对已采集的单篇 Markdown 形成最小证据包并返回自然语言回答
- [ ] 回答中的关键结论关联稳定来源身份和人类可核验的来源定位
- [ ] 当材料不能回答问题时，系统明确说明证据不足，而不是依靠模型常识猜测
- [ ] 新项目使用提供方中立的生成接口，首个真实适配器通过 OpenAI Responses API 工作
- [ ] API 凭据仅从进程环境或操作系统凭据机制获得，不出现在仓库、Vault、输出或普通日志中
- [ ] 每次云端调用都要求当次明确授权；过去的授权不会自动沿用
- [ ] `local-only` 内容在任何情况下都不会传给生成适配器，缺失或无效的敏感级别不会被静默视为可外发
- [ ] 生成适配器只能收到证据包而不能读取整个 Vault 或永久对象存储
- [ ] 每次外发记录时间、提供方、模型、目的、来源身份和非敏感请求指纹，但不复制完整原文
- [ ] 提供方超时、拒绝或返回无效结果时，命令返回稳定错误且不改变永久知识
- [ ] 验收测试使用确定性假生成适配器检查确切外发内容；真实 OpenAI 适配器仅通过独立契约测试验证转换
