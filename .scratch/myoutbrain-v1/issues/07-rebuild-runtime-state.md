## Answer

已实现 `myoutbrain rebuild`：它从内容寻址来源对象、轻量来源记录、Vault 知识笔记和永久演变事件验证并重建版本化来源目录与第一版全文投影。重建严格检查来源哈希与时间、知识元数据、洞见到认知的晋升关系、认知取代关系，以及各类永久事件的必需字段和相互一致性。

新投影在独立目录完成后通过单一活动指针原子激活，并保留上一代供失败恢复；激活后的旧代、候选工作区、缓存和日志只做不影响成功结果的尽力回收。查询在活动投影存在时会读取并与永久来源交叉校验，删除整个 `runtime/` 后会明确要求重建，重建前后的来源问答和完整知识/关系摘要保持一致。

验收测试覆盖运行层删除、来源与完整认知演变恢复、临时候选不恢复、重复重建、损坏永久事件、活动切换硬中断，以及失败后旧查询与候选行为继续可用。
