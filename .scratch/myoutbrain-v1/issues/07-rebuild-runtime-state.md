# 07 — 从永久知识重建运行状态

**What to build:** 让单一创作者在目录、全文投影、缓存和工作区被删除或损坏后，通过 `rebuild` 从原始材料、轻量记录、知识笔记和事件重新获得可查询的私人认知库。

**Blocked by:** 06 — 显式晋升个人认知

**Status:** ready-for-agent

- [ ] 删除全部可重建运行数据后，`rebuild` 能重新生成目录和第一版所需的全文投影
- [ ] 重建前后的来源、衍生洞见、个人认知、取代关系和 CLI 查询结果在外部行为上保持一致
- [ ] 临时候选、缓存和普通运行日志不会被误判为必须恢复的永久知识
- [ ] 重建可重复执行，并在相同永久输入下产生确定且幂等的可观察结果
- [ ] 单个损坏永久记录会被准确指出，命令返回完整性错误，同时有效记录不会被删除或改写
- [ ] 重建过程使用临时投影和原子切换，失败时继续保留此前可用的运行状态
- [ ] SQLite 等运行目录仅作为投影，验收测试证明删除它不会丢失永久知识
- [ ] 重建测试通过 CLI 比较删除运行数据前后的用户行为，不断言内部数据库布局
