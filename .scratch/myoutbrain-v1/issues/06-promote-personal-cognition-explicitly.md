# 06 — 显式晋升个人认知

**What to build:** 让单一创作者通过与候选审阅分离的明确操作，将本人真正认可的衍生洞见晋升为个人认知，并在观点改变时保留可追溯的认知演变。

**Blocked by:** 05 — 审阅并晋升衍生洞见

**Status:** ready-for-agent

- [ ] 只有用户明确发起的晋升操作才能把衍生洞见变为个人认知
- [ ] 生成适配器、反思逻辑和候选审阅动作都无法绕过该人工晋升步骤
- [ ] 晋升目标必须是有效且活动的衍生洞见，其他类型或状态返回稳定错误且不修改数据
- [ ] 晋升结果使用 `kind: cognition`，并如实保留原始来源、系统参与和用户认可信息
- [ ] 用户可以用新个人认知取代既有认知，旧认知变为 `superseded` 而不被删除
- [ ] 新旧认知记录双向可追溯的取代关系，重命名知识笔记不会破坏关系
- [ ] 晋升和取代写入知识演变事件，并在中断时保持原子一致
- [ ] 验收测试覆盖允许与禁止的全部状态转换，特别证明 AI 内容绝不会自动成为用户立场
