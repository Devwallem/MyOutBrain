# 04 — 从证据生成候选洞见

**What to build:** 让单一创作者可以通过 `reflect` 请求系统审视已采集材料，并得到可批判检查、不会自动污染永久知识的候选洞见。

**Blocked by:** 03 — 基于证据包回答材料问题

**Status:** claimed

- [ ] `reflect` 使用证据包生成候选洞见，而不是直接写入 Obsidian 永久知识
- [ ] 每个候选洞见包含支持证据、发现时的反对证据、推导摘要和稳定候选身份
- [ ] 候选记录明确标记为系统产生且尚未经创作者审阅
- [ ] 候选只存在于可回收工作区，并携带可配置的过期信息
- [ ] 材料上等价或高度相似的候选被合并，而不是反复保存正文副本
- [ ] 合并候选会累计出现次数和最近出现时间，使重复出现可见
- [ ] 已拒绝候选的轻量指纹能够抑制立即重复生成，同时不永久保留不必要正文
- [ ] 生成失败、证据不足或工作区写入失败时，不产生部分候选或永久知识变化
- [ ] 验收测试证明多次反思不会造成候选数量按调用次数无界复制
