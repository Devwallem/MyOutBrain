# 02 — 幂等采集 Markdown 原始材料

**What to build:** 让单一创作者可以通过 `capture` 采集一篇本地 Markdown，将原始内容、来源和稳定身份安全加入私人认知库，并确保重复采集不会重复占用对象存储。

**Blocked by:** 01 — 初始化私人认知库

**Status:** ready-for-agent

- [ ] 采集有效 Markdown 后产生稳定来源身份、来源记录和可审计的采集事件
- [ ] 原始字节以 SHA-256 内容寻址并保持不可变，记录能够追溯内容哈希、原始出处和采集时间
- [ ] 对完全相同内容重复采集时复用已有对象并明确报告重复结果
- [ ] 相同内容使用不同文件名采集时仍被识别为同一对象，同时保留必要的来源信息
- [ ] 文件名改变不会改变已建立的稳定身份或破坏已有引用
- [ ] 缺失、空白、不可读或无效的 Markdown 返回稳定用户错误，并且不写入部分对象、记录或事件
- [ ] 采集在项目锁保护下使用原子提交；模拟中断后只能观察到完整旧状态或完整新状态
- [ ] 并发采集时只允许一个写入者继续，其他写入者收到明确锁冲突
- [ ] 重复采集和失败采集的验收测试证明对象数量不会无界增长
