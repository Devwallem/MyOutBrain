# 01 — 验证对话沉淀与经验召回闭环

**Type:** prototype

**Status:** resolved

**Prototype branch:** `codex/dialogue-learning-prototype`

**Question:** 对话只保存一次、提炼产物仅引用 turn ID 时，人工审阅、指纹去重和回答前召回的状态模型是否符合真实使用直觉？

## Run

```powershell
.\.venv\Scripts\myoutbrain-dialogue-prototype.exe
```

## Observe

- 未接受的候选不得参与召回
- 重复对话不得生成第二份相同教训
- 拒绝后只保留轻量指纹
- 无价值闲聊不得生成可复用产物
- 新问题只能召回已经人工接受的经验

## Answer

用户完成两轮人工验证后确认修订模型“感觉还行”。最终采用“输入当前可见对话并提炼 → 为实际候选动态编号 → 人工接受或拒绝 → 只有已接受记忆参与未来召回”的交互顺序。数字键只选择本轮真实候选，不预设 GitHub、Vault 或固定经验类型。

原始对话仍只保存一次，提炼产物只引用证据 turn ID；重复内容受到指纹抑制，拒绝后只保留轻量指纹，明显闲聊不生成可复用候选。原型已回答状态模型问题；真实模型提炼、持久化和智能体适配继续由正式同伴记忆闭环承担。
