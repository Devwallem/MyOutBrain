# 10 — 定时整合、受限云端分析与本机通知

**What to build:** 在手动整合之外提供定时和紧急强制整合；定时任务可以在可撤销的持续授权内使用云端分析，但只能生成待审阅提案，并在无活跃对话时通过本机通知提示用户。

**Blocked by:** 05 — 修订知识并保留冲突与演变.

**Status:** claimed

- [ ] 用户可以手动、按明确计划或为紧急任务强制启动整合，系统不会自行猜测空闲状态或剩余额度。
- [ ] 强制整合可以在重要回答前处理相关缓冲内容，但仍须遵守语义提案与人工批准边界。
- [ ] 定时云端授权固定提供方、模型、允许敏感度、批大小、令牌上限和费用上限，并可随时撤销。
- [ ] `local_only` 内容始终排除在云端批次外，越权、超批或超预算请求不会发出。
- [ ] 无论本地还是云端分析，语义结果只能生成提案，不能自动修改规范记忆。
- [ ] 确定性去重与索引维护可自动提交，并与语义变化审计清楚区分。
- [ ] 完成的提案在有活跃对话时立即交付；无活跃对话时进入待审阅队列并发送本机通知。
- [ ] 使用确定性能力与通知替身的测试覆盖计划触发、授权边界、失败重试、提案只读和通知交付。
