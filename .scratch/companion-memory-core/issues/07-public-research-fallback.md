# 07 — 知识不足时检索公开信息

**What to build:** 让系统对实质性问题执行二元充分性判断；内部证据不足、陈旧、冲突或高风险时，以脱敏查询补充公开信息并重新判断，最后给出可追溯答案，或诚实展示仍未知的部分。

**Blocked by:** 02 — 通过记忆网关召回缓冲内容.

**Status:** resolved

- [x] 内部证据只有在足以支持完整结论时才通过充分性门；部分可答、过时、冲突或高风险证据均视为不足。
- [x] 不足时生成不包含私人正文、私人身份或无授权敏感细节的公开查询。
- [x] 私人上下文只有在显式授权和敏感度规则允许时才可发送给外部能力。
- [x] 公开检索结果经过来源、时效与冲突检查后重新进入同一个充分性门。
- [x] 通过门的自然回答能够区分共同知识、公开证据和同伴推断，并对变化、争议、高风险或网络来源给出关键依据。
- [x] 检索后仍不足时不生成综合结论，而是列出已验证事实、未决缺口和下一步验证方式。
- [x] 每个实质性回答至多提交一条引用本轮证据的紧凑缓冲更新，不直接写入规范记忆。
- [x] 使用确定性公开检索与生成替身的 CLI 验收测试覆盖充分、检索后充分和检索后仍未知三条路径。

## Answer

已实现二元回答充分性门、显式风险/时效分类、公开安全查询边界、HTTPS 公开检索适配器，以及来源/时效/冲突复核。公开结果仍不足时只展示已验证事实、缺口和下一步；充分回答会区分共同知识、公开证据与同伴推断，并至多写入一条带引用的缓冲更新。
