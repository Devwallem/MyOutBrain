# 03 — 召回措辞不同但语义相近的记忆

**What to build:** 在同一个召回接口后加入默认本地运行的语义候选召回，使不同措辞表达的相近理解能够被发现，同时保证向量相似度只扩展候选、不能决定事实、合并知识或覆盖原有召回。

**Blocked by:** 02 — 通过记忆网关召回缓冲内容.

**Status:** resolved

- [x] 本地 Embedding 默认可用，并能召回测试集中措辞不同但语义等价的缓冲与规范记忆。
- [x] 语义结果与稳定关系、全文检索结果在同一深层召回接口内组合，调用方看不到向量存储细节。
- [x] 每代语义索引记录提供方、模型、维度和规范化版本，互不兼容的向量空间不会混用。
- [x] 删除语义索引后可以从规范数据重建，重建不会改变记忆身份或规范内容。
- [x] Embedding 不可用或生成失败时，系统退化到稳定关系和全文检索并继续工作。
- [x] `local_only` 内容不会发送给云端 Embedding；可选云端适配器只有在实例明确授权后才可接收合格内容。
- [x] 相似候选不会自动触发答案成立、知识合并、冲突解决或规范写入。
- [x] 版本化召回评估包含同义表达、缓冲内容和词法基线的对比结果。

## Answer

已在现有 `MemoryGateway.recall` 后加入语义候选阶段。新实例初始化时准备 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` 多语言模型，正常召回只读取本地缓存；模型缺失、生成失败或索引损坏时会回落到稳定关系与全文检索。可重建索引按敏感度分区，每代记录 provider、model、dimensions、normalization version、内容指纹与稳定记忆 ID；删除后可由规范记忆和记忆简记自动重建，切换不兼容空间会原子替换而不会混用。

语义命中以 `semantic-candidate` 进入同一最小证据包，稳定身份、来源关系和全文结果仍优先，`answerability` 保持保守的 `insufficient`，不会触发合并、冲突处理或规范写入。云端适配器默认完全禁用；只有查询显式标为 `cloud-allowed`，且实例同时确认 provider、model、发送范围、预算和单次文本上限时才可调用，并始终过滤 `local-only` 记忆。版本化 `semantic-recall-v1` 评估覆盖同义措辞、缓冲内容和词法对照（语义 3/3，词法 1/3）。完整测试、严格 mypy、编译检查、diff 校验以及 Standards/Spec 双轴复审均通过。
