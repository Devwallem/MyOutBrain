# 分流标签

工程技能使用五个规范分流角色。下表将这些角色映射到本仓库事项跟踪器实际使用的状态字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此事项 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可交给自主代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某个角色（例如“应用可交给代理的分流标签”）时，使用上表对应的状态字符串。

如需适配已有词汇，可直接编辑右侧“本仓库中的标签”列。
