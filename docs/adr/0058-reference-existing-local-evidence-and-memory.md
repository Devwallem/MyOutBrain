# 引用已有本地证据与知识而不复制内容

V2 对已存在的本地来源只新增由 `source_id`、来源版本和定位组成的证据引用，不复制正文；路径和名称是可更新别名，内容变化产生新的来源版本。新知识若依赖已有规范记忆，则建立可追溯的知识依赖并沿关系图继承其来源影响范围。完全重复的知识直接归并到现有稳定身份：来源也相同时不产生变化，来源不同时只合并去重后的来源关系，不创建新版本或语义审阅提案；相近但有语义差异的内容才生成补充、修订或冲突提案。

## Consequences

关系执行器必须拒绝自我依赖以及没有外部来源出口的循环依赖。证据片段、关系边和上下文清单都使用稳定身份并支持复用；精确去重与来源归并属于不改变语义的确定性维护，可以自动执行。只有不再被知识、提案或审计引用的对象才能进入垃圾回收候选。
