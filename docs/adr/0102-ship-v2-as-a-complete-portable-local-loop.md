# 将 V2 作为完整可迁移本地闭环发布

V2 首个完整发布必须包含 SQLite 规范存储与内容寻址对象存储、知识字典、分区树和有界胶囊；基础召回、两阶段证据展开、二元可回答性契约及召回日志；统一审阅提案、批次决定、反证工单和批准物化；Companion、Reflector、待反思队列与计划领取；MCP 主入口、CLI 后备、协议与能力协商；Codex、OpenCode、Claude Code 三个薄适配器；手动增量迁移 ZIP、整库冷快照、`doctor`、垃圾回收计划，以及自动无损胶囊重组和基础召回回归测试。

Embedding 只保留可选接口，其具体实现，无人值守 headless 能力引擎、Web 或专用桌面 UI、固定 Obsidian 展示、实时同步、多用户协作、加密密钥体系、个性化权重、推荐算法和自动知识批准均不阻塞 V2 发布。

## Consequences

V2 的完成标准是跨智能体可实际使用的知识闭环，不是孤立的数据模型或 Codex 专属原型。实现工作必须按垂直切片推进并保持 CLI 可验收，非目标能力不得借“预留”引入运行依赖或复杂配置。
