# 由本地核心与能力引擎共同执行可回答性门槛

V2 的本地核心负责返回规范记忆正文、生命周期状态、适用范围、必要依赖、未决反证和可用来源摘要；当前能力引擎结合创作者的实际问题，判断材料是否覆盖所求范围、满足必要时效并解决实质冲突。能力引擎以结构化 `answerable: true|false` 返回本轮判断，失败原因限制为覆盖不足、时效不足、依赖缺失或冲突未决等稳定类别。

本地核心校验输出结构并执行不依赖语义推断的硬规则，例如不能在仍携带未决实质反证时声明“无冲突”。它不脱离问题自行估算语义充分性；能力引擎也不能忽略核心提供的状态。可回答性只属于当前请求，不保存为知识权重、规范记忆状态或自动修订依据。

## Consequences

不同智能体可以使用各自推理能力，同时遵守相同门槛契约。不可回答时入口仍可呈现已核验事实、关键未知和下一步验证方向，但不能把这些内容包装为完整结论；公开检索或用户补充材料后可以重新运行同一判断。
