# 审计知识迁移而不预设环境隔离

V2 不把个人机器、公司机器或特定智能体客户端视为必须隔离的知识域。程序、适配器和知识数据使用统一可迁移格式；每次导入导出根据目标环境、来源许可、敏感度和证据依赖执行迁移审计，决定允许、脱敏、排除或阻止的内容。迁移包保留稳定身份、版本、来源关系和签名清单，导入先查重、验证兼容性并把语义冲突送入统一审阅队列。

## Consequences

同一知识体系可以在不同工作环境和 Codex、OpenCode、Claude Code 等入口之间持续迭代，环境标签本身不构成硬性禁止。系统仍不能把导入导出退化为无审计文件复制；实际组织政策和来源授权必须由迁移规则表达并在执行前展示。
