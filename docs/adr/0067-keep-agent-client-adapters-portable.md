# 保持智能体客户端适配器可移植

V2 把 Codex、OpenCode、Claude Code 及未来客户端视为可替换智能体入口。客户端专属 Skill、命令、规则或插件只做薄适配，共享版本化领域协议、JSON 数据形状、稳定身份和能力协商；私人实例、计划、审阅队列、证据关系、规范记忆和迁移逻辑全部留在独立本地核心。MCP 是优先但非强制的互操作入口，机器可读 CLI 是最低共同能力。

## Consequences

公共发行需要提供可独立安装的本地核心和按客户端选择的入口适配器，不把模型名称、会话格式或客户端路径写入规范知识。适配器可以分别迭代和替换，但必须通过同一协议契约与兼容性测试，不能产生客户端专属用户模型。
