# 使用带清单的普通 ZIP 迁移包

V2 将个人知识库视为可以由创作者在本机直接查看和自行选择传输渠道的内容，因此迁移包使用普通 ZIP，不内建实例密钥、数字签名、公钥配对或恢复密钥。包内保留版本化机器清单、对象与关系哈希、迁移检查点和依赖闭包审计结果，用于检测损坏、执行 dry-run、精确去重和幂等导入；传输保密性由创作者选择的远程渠道或外部压缩工具负责。

本决策取代 ADR-0071 的默认公钥加密与签名方案。V2 不宣称普通 ZIP 可以抵抗恶意篡改；如果未来出现真实敏感迁移需求，再依据使用场景增加可选加密层，而不是预先维护个人密钥基础设施。

## Consequences

定期打包和跨客户端迁移保持简单，任何环境都可以用常见工具检查包内容。导入仍必须通过格式、哈希、依赖闭包和语义冲突检查，简单容器不等于跳过迁移审计。
