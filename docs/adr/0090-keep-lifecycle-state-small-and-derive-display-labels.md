# 保持生命周期状态精简并动态推导展示标签

V2 每条规范记忆只持有一个封闭的生命周期状态，初始集合为 `current`、`historical-trusted`、`superseded` 和 `inactive`。状态迁移必须遵守知识修订和统一审阅规则。`conflicted` 根据未决反证关系或审阅提案实时推导，`external-unintegrated` 属于外部证据或提案，二者都不扩充规范记忆状态集合。

知识、经验、技能、偏好或研究灵感等内容视角由入口根据任务动态生成展示标签；数学、数论等主题位置由知识分区树和交叉引用表达，不复制为永久主题标签。只有创作者明确需要跨树人工筛选的少量自定义标签可以持久保存，其创建、合并和删除必须经过审阅，不从模型输出或使用频率自动增长。

## Consequences

核心查询和迁移协议只需要理解很小的状态集合，各客户端仍可自由呈现适合自己的标签。派生标签可以随模型和任务变化而变化，不能被当作规范身份、知识权重、融合条件或可靠审计字段。
