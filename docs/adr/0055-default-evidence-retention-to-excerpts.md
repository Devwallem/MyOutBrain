# 默认保留必要证据片段

V2 使用 `full`、`excerpt` 和 `receipt` 三档证据保留级别，并以 `excerpt` 作为普通对话、任务记录和一般本地材料的默认值。不可重新获取的私人原创、关键决策、高风险依据和创作者指定内容使用 `full`；可重新获取的公开资料及低风险可重复工具结果可以使用 `receipt`。系统可以提出保留级别降级建议，可重复公开来源可在既定存储预算内自动降级并记录审计，但不可重新获取内容的降级必须明确确认，来源凭证的永久删除继续走显式删除流程。

## Consequences

同伴保留足以复核结论的上下文而不默认囤积完整对话。能力引擎和入口必须在采集时标明保留级别及其理由；以后若需要重新解释但证据只剩凭证，系统应报告限制并尝试按定位重新获取，而不能虚构已保存原文。
