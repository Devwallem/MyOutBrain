# 保持历史可信知识可召回

V2 不因时间流逝、来源暂时不可用或验证周期到期而排除曾经批准的知识。缺少当前时效依据的规范记忆降为 `historical-trusted`，对当前事实问题与尚未整合的公开证据处于同一候选层级，可以展示、互相印证、形成冲突或触发进一步验证；回答历史问题时仍可直接说明当时采纳的理解。只有统一审阅流程记录的明确决定才能让知识退出当前共同知识基线。

最终可回答性继续使用二态门槛，但由当前知识、历史可信知识和公开候选证据的组合共同判断相关性、覆盖度、时效性、来源质量与冲突。历史可信知识不会因为降权而消失，也不能在当前问题中无提示地伪装成现行事实。

## Consequences

召回结果需要同时表达规范身份和时态层级。来源关系图必须支持从新证据定位历史版本；退出当前基线与永久删除保持分离，旧知识继续解释过去决策及知识演变。
