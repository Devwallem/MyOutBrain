# 不维护独立的知识权重系统

V2 不为规范记忆保存可信度权重、随时间衰减的分数、个性化排序参数或由多个特征组成的综合等级。知识当前处于共同基线、历史可信、已取代或存在冲突等语义由既有状态与关系表达；特别是 `historical-trusted` 不会因为继续变旧而自动降低数值或退出召回。

字典、分区树、全文检索和可选语义召回器可以在一次请求内产生临时相关度，用于在召回字节预算内选择候选；该数值不持久化、不跨请求累积，也不能判断知识真伪。冲突和必要依赖通过已有关系随候选带入，最终能否给出结论仍由二元可回答性门槛决定。

## Consequences

系统避免维护一套与状态标签重复且难以审计的评分模型。若未来真实回归测试证明简单候选截断不足，应先改进名称、别名、树路由和全文索引；任何持久排序学习都需要新的明确决策，而不能从使用行为中悄然出现。
