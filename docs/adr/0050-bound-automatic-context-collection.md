# 限定自动上下文采集范围

V2 反思调度器采用三级读取边界：默认读取当前可见对话、系统摘要、活动事项、已产生的工具结果、当前差异和任务相关网关证据；为核验或去重可以自动扩展到少量直接相关的本地文件、提交、ADR 和既有提案；其他仓库、完整历史、外部连接器及私人内容云端处理必须获得显式授权。每次反思都列出实际覆盖范围与盲区，并在候选已有可核验来源、适用边界和去重判断后停止扩展。

## Consequences

自动化不再意味着无边界扫描。Skill 可以在活动任务内自行完成低风险的相关本地读取，但不能声称访问了隐藏历史，也不能用“需要更完整上下文”为理由默认遍历整个私人实例或把内容发送给外部能力。
