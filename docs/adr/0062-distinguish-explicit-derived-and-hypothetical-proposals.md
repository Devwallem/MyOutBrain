# 区分明确陈述、系统推导和待验证假设

V2 为每个审阅提案记录 `explicit`、`derived` 或 `hypothesis` 形成方式。明确陈述来自创作者直接表达的事实、决定、偏好或修正；系统推导可以从多个来源、结果和重复模式提出教训、方法或联系，但必须展示推导过程及支持与反对证据，并在批准后继续保留系统推导身份；证据不足的联想只能作为研究假设，不能直接成为规范事实。形成方式不取代 `derive`、`integrate`、`archive` 和 `research` 提案意图。

## Consequences

Skill 可以主动总结跨任务经验而不局限于摘录原句，但没有可追溯证据的内容不生成提案，行为观察也不能自动升级为创作者稳定偏好或个人认知。模型自报置信度不产生额外权限。
