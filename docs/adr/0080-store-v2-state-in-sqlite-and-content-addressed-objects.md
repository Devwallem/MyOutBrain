# 使用 SQLite 与内容寻址对象保存 V2 状态

V2 使用 SQLite 作为知识身份与版本、来源凭证、规范关系、审阅提案、审阅批次、计划、迁移检查点和审计索引的状态事实来源；`full` 与 `excerpt` 证据正文进入内容寻址对象存储并按内容复用。追加式事件日志记录审阅、版本变化、迁移和删除操作，用于审计与恢复，但系统不采用完整事件溯源。Embedding、全文索引、证据关系图索引、Obsidian 视图和审阅视图都是可删除重建的投影。

## Consequences

跨对象写入需要由本地核心原子协调，备份与迁移包必须同时覆盖 SQLite 规范状态和被引用对象。Markdown 和客户端视图不能成为机器事实来源，事件日志也不能替代经过验证的当前状态查询。
