# 分离记忆正文、知识胶囊和召回预算

V2 为三层大小分别设置初始默认值：单条规范记忆正文目标不超过 4 KiB、硬上限 8 KiB，知识胶囊目标约 64 KiB、硬上限 128 KiB，单次普通召回默认最多向能力引擎发送约 16 KiB 选中记忆。超过正文上限的材料留在证据层，规范记忆只保存紧凑理解；胶囊达到硬上限或内部主题明显分化时裂分，相邻胶囊合计低于目标且主题一致时可以合并。复杂研究和高影响任务可以显式提高召回预算。

## Consequences

本地胶囊可以高效批量读取而不会整块进入模型上下文。存储限制以字节为稳定单位，各入口根据能力引擎转换为 token 预算；默认值必须可配置并由真实召回回归集校准，不能假设所有模型拥有相同上下文窗口。
