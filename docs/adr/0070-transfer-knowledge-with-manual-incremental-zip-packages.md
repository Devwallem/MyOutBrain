# 使用手动增量 ZIP 包迁移知识

V2 不实现实时双向同步。创作者定期手动选择自上次迁移检查点以来新增或变化的知识，系统计算依赖闭包并执行 fail-closed 审计，通过后生成版本化 ZIP 迁移包；包内包含机器可读清单、规范对象、稳定身份、版本、来源关系和检查点。目标环境先 dry-run 展示新增、精确去重、来源归并、版本冲突和阻止项，确认后幂等导入；相同包重复导入不重复创建知识，两边独立修改同一知识时生成冲突提案。

## Consequences

远程传输由创作者选择现有渠道完成，本地核心不维护后台同步服务。ZIP 只是可移植容器，不能省略迁移审计、完整性验证和导入预览；导出检查点只有在包成功生成后推进，导入检查点只有在事务完成后记录。
