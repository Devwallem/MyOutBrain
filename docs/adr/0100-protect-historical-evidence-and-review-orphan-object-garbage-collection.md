# 保护历史证据并审阅孤立来源对象回收

V2 可以在确认不再被运行引用后自动清理临时反思输入、过期租约、中断胶囊重组副本和可重建索引。任何仍被 `current`、`historical-trusted`、`superseded` 或 `inactive` 规范记忆引用的来源对象都不是垃圾；待审提案、审计事件或未完成迁移闭包引用的对象，也在相应保留期内受保护。

对象正文按内容哈希全局去重，某一条关系消失不会立即删除共享对象。确认不再被任何规范数据引用的来源对象进入垃圾回收计划，列出体积、最后引用和删除影响，由创作者显式执行 `gc apply`；大型原始证据仍需逐项或明确批次确认。删除后只保留不含正文的最小删除标记，阻止旧缓存或重复迁移静默恢复内容。

## Consequences

历史知识不会因退出当前基线而丢失来源，自动维护也不会越权删除规范证据。引用闭包检查必须覆盖数据库关系、对象清单、提案保留和迁移租约；误判为孤儿属于完整性故障，不能用普通垃圾回收掩盖。
