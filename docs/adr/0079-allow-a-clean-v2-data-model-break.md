# 允许 V2 直接建立新的数据模型

当前 MyOutBrain 仍处于架构阶段，私人实例尚未填充需要保留的真实知识。V2 因此不实现 V1 候选洞见、第一阶段整合提案和项目内实例到统一审阅模型的语义迁移器，也不维持旧 CLI 与数据库 schema 的兼容层；实现可以直接删除或替换重复生命周期，并用新的主私人实例和测试数据重新初始化。Git 历史、ADR 和验收测试继续作为设计演变依据。

## Consequences

V2 可以采用更清晰的统一提案、证据关系和主实例结构，而不为一次性迁移增加长期复杂度。开始导入真实私人知识后，后续 schema 版本必须恢复正常的计划、备份和可恢复迁移纪律；这次破坏性窗口不能成为以后随意重置数据的先例。
