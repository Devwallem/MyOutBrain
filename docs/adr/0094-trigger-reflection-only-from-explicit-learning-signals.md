# 仅由明确学习信号触发自动反思

V2 允许创作者显式调用反思并立即执行。普通任务结束时，`myoutbrain-companion` 只检查是否出现明确学习信号：用户纠正、已确认决策、可复用步骤、重复失败及解决办法或值得追踪的研究问题；没有此类信号时不保存待反思输入，也不创建空运行。

普通学习信号进入本地待反思输入，默认每周集中生成一次审阅批次；周期和计划任务是否启用均可配置。只有会阻塞当前高风险工作的反证或知识缺口才立即形成 `blocking` 提案。系统不使用消息数、token 数或单纯经过时间作为知识价值代理，队列为空时计划任务也不唤醒能力引擎。

## Consequences

反思成本随有意义事件而不是聊天总量增长，批次审阅也不会被空洞摘要填满。入口适配器必须以相同信号契约调用 Companion；信号只授权生成提案，不授权写入规范记忆。
