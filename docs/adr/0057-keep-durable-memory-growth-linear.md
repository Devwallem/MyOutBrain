# 保持持久记忆关系近似线性增长

V2 要求持久数据量随唯一来源、批准记忆版本和明确证据关系近似线性增长。系统只持久保存支持、反驳、派生、验证和取代等可解释关系；语义相似度只用于查询和整合期间的临时候选，禁止构建永久的全量相似网络。相同来源按内容身份复用，重复观察不创建新正文；规范记忆在稳定身份下增加版本，待审提案受期限约束，可重建索引只保留当前兼容版本。

## Consequences

存储报告必须把唯一证据、规范语义、待审缓冲和可重建投影分开计量。超过预算时系统提出压缩、证据级别降级或删除建议，但不能为了维持线性目标自动删除不可替代证据。任何可能让关系数接近平方增长的设计都应视为架构违规。
