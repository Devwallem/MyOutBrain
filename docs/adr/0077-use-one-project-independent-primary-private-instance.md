# 默认使用一个独立于项目的主私人实例

V2 为单一创作者默认注册一个独立于代码仓库、工作区和智能体客户端的主私人实例。Codex、OpenCode、Claude Code 和不同项目通过本地核心连接该实例；项目只提供任务范围、来源和召回边界，不拥有或复制知识库。跨项目通用经验可以复用，项目专属内容继续由任务范围和证据关系限制。只有出现明确的不同身份或用途边界时才显式创建其他命名实例。

## Consequences

V2 入口适配器需要通过本地实例注册表或统一配置发现主实例，不再优先把当前目录中的 `myoutbrain.toml` 当成知识所有者。现有项目内实例需要迁移或登记为命名实例，不能在客户端切换时自动新建孤岛。
