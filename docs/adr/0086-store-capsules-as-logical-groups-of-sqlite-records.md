# 将知识胶囊实现为 SQLite 记录的逻辑分组

V2 的知识胶囊是有界逻辑存储单元，不是单个整体 JSON、Markdown 文件或不可分割的大对象。SQLite 中的胶囊记录保存身份、树位置、主题路由、容量和结构版本；每条规范记忆正文保持独立记录并通过 `capsule_id` 归属主胶囊。知识字典以 `capsule_id + memory_id` 定位正文，不保存容易失效的文件字节偏移。

入口既可以按 `memory_id` 读取单条知识，也可以在一次有界查询中读取整个胶囊。裂分与合并在事务中复制记录并切换归属，而不重写一个大型文件；超过规范记忆大小预算的证据正文和附件继续存入内容寻址对象存储。迁移包按公开格式重新组装逻辑胶囊，不把 SQLite 页布局当作交换协议。

## Consequences

设计保留胶囊的局部性和批量读取效率，同时减少文件碎片、整块重写与格式耦合。实现必须用约束保证每条当前记忆只有一个主胶囊，并为胶囊容量统计、结构版本、复制切换和孤儿记录清理提供事务性检查。
