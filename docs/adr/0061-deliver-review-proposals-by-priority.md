# 按优先级交付审阅提案

V2 将审阅提案分为 `blocking`、`priority` 和 `routine`。只有反证或缺口影响当前高风险决定、不可逆行动或让任务无法可靠继续时使用 `blocking` 并暂停相关行动；不阻塞当前任务的重要冲突、修订和重复失败使用 `priority`，在任务结束后置顶提示；普通知识、经验、技能、归档和研究建议使用 `routine`，按数量阈值或明确计划批量交付。创作者可以随时主动打开统一队列。

## Consequences

提案优先级只控制交付时机，不改变证据权重、执行权限或审阅要求。常规提炼不会把每次交流变成审批操作，高影响冲突也不会隐藏在离线批次中。
