# 安装一个本地核心并注册可替换客户端适配器

V2 将本地核心和主私人实例数据目录独立安装一次，再通过统一命令为 Codex、OpenCode、Claude Code 等客户端生成或注册 MCP 配置、Skill 与薄适配文件。所有入口指向同一个核心，不复制数据库、知识胶囊或私人配置。适配器安装是幂等操作，可以安全重装和卸载；删除入口绝不隐式删除知识库。

核心与入口分别升级，安装器根据能力协商规则报告兼容矩阵。统一 `myoutbrain doctor` 检查核心版本、数据完整性、协议兼容、入口配置和计划任务。私人配置及数据不进入客户端插件目录，也不会被适配器模板更新覆盖。

## Consequences

创作者切换智能体只需安装另一个入口，不必迁移知识或维持同步。实现需要为各客户端保留很薄的模板与契约测试，并让卸载、修复和升级命令清楚区分入口文件、核心程序和私人数据。
