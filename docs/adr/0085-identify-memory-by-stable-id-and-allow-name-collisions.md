# 用稳定身份标识知识并允许名称碰撞

V2 以稳定 `memory_id` 作为规范记忆身份，显示名称和别名只作为知识字典的发现入口，不作为主键。规范化后的名称或别名可以映射到多个候选，入口适配器结合知识分区、任务上下文、当前版本状态和明确限定词完成消歧；调用者也可以用 `memory_id` 或“分区路径 + 名称”确定性定位。

知识改名时，旧名称默认保留为重定向别名，使既有引用和人的记忆继续有效。同一别名可以合法指向不同领域的知识，名称碰撞本身不得触发自动合并；只有内容、语义范围与作用等价时，才按精确知识去重规则复用既有身份。

## Consequences

知识可以随领域树演化而改名或移动，不会因此改变身份。字典查询需要返回带分区和摘要的候选集合并明确表示歧义；别名重定向要防止循环，确定性接口不得在多个候选之间静默任选一个。
