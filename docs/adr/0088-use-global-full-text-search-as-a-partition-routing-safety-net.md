# 用受限全库全文检索保护分区路由召回

V2 不允许知识分区树成为召回的唯一入口。稳定身份、名称和别名始终通过知识字典全局查找；全文检索先为树选中的胶囊提供高优先级局部候选，同时或在局部结果不足时执行受限的全库 FTS 查询，只返回少量 `memory_id`。越区候选可以纠正摘要过时、归类不准和跨领域问题造成的漏召回，但仍须通过知识字典读取规范正文。

全库 FTS 只访问本地可重建索引和候选身份，不向能力引擎发送整个知识库。若同一知识长期通过越区搜索纠正相同路由，本地核心可以据此自动新增或调整无语义的树路由线索和交叉引用；调整不得移动或改写知识正文，超出无损维护边界时必须生成审阅提案。

## Consequences

召回质量不会完全依赖某次树摘要或分区选择，而全库安全网的成本仍受候选数量和查询超时约束。评测需要分别记录树内命中、越区纠正率和无关候选率，使自动路由维护可以被回滚和校准。
