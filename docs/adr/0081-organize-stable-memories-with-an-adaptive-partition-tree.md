# 用自适应分区树组织稳定规范记忆

V2 保持规范记忆的稳定身份和版本，并在其外建立类似 B 树逐步裂分的知识分区树。知识较少时使用数学等宽板块，内容增长且内部主题分化后裂分为离散数学、数论等子分区，稀疏相近分支可以合并；裂分、合并和移动只重组记忆引用，不复制正文或改变规范语义。父分区保存可重建导航摘要，一条记忆可以被多个分区引用，跨领域语义继续由知识和证据关系图表达。

## Consequences

分区树是可删除重建的组织与召回投影，不是事实来源或固定文件夹体系。分区路径不能成为规范记忆身份，外部引用应使用稳定记忆或分区身份；重新聚类和能力引擎替换不得改变知识版本及其来源关系。
