# 默认按需运行本地核心

V2 不要求安装常驻后台 daemon。支持 MCP 的 Codex、OpenCode、Claude Code 等入口按需拉起本地 stdio MCP 进程，不支持 MCP 的入口使用机器可读 CLI；多个短生命周期进程通过主私人实例的锁、事务和幂等身份协调。定时反思由 Windows Task Scheduler、cron 等操作系统计划工具调用 CLI，计划、授权、重试、提案和通知状态仍由本地核心持久化。

## Consequences

默认安装不需要维护端口、服务权限或常驻进程，客户端适配器更容易即插即用。未来若实时事件、长任务或并发规模证明需要 daemon，可以在相同领域协议上增加可选宿主，但不能成为核心闭环的唯一运行方式。
