# 运行独立本地核心并以 Codex 作为首个入口

MyOutBrain 第一阶段由独立本地核心拥有私人实例、记忆网关、SQLite 规范记忆、内容寻址对象、全文与 Embedding 索引、计划整合和本机通知，Codex 通过 Skill 成为第一个主要智能体入口，CLI 负责初始化、诊断、手动或计划整合、审阅、遗忘、重建和存储报告。入口在实质任务前自动查询记忆网关并在任务后提交经历简记，但只能保存当前实际可见的任务上下文和稳定指针，必须标明不可见历史；未来网页、手机或其他智能体复用同一接口，核心知识与关系连续性不绑定 Codex、模型或渠道。
