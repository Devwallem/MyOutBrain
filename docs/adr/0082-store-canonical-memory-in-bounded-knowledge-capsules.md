# 用知识字典和有界胶囊保存规范记忆

V2 使用知识字典保存稳定记忆身份、名称、别名、当前版本状态以及主知识胶囊记录位置。知识分区树的内部节点保存主题范围、子节点路由、紧凑摘要和跨分区线索，有界叶知识胶囊聚合语义相关的唯一规范记忆正文；完整证据继续由来源凭证、证据引用和对象存储管理。一条记忆只有一个主胶囊和一份正文，可以在其他分区留下交叉引用。

胶囊裂分或合并时先创建新胶囊并重新分配记录，再原子更新知识字典指针；旧胶囊在并发读者安全退出前保留重定向线索。精确查询通过字典定位记录，主题查询沿树选择少量胶囊，语义召回只产生 memory ID 候选并经字典读取；最终证据包只包含选中的记忆，不把整个胶囊发送给能力引擎。本决策取代 ADR-0081 将分区树整体视为纯投影的设计：叶胶囊承载规范正文，内部摘要、Embedding 和人类导航视图仍可重建。

## Consequences

胶囊移动和树重组不得改变记忆身份、版本或来源。知识字典、胶囊写入和重定向回收需要原子协调与完整性检查；跨分区引用不能复制正文，循环路由也不能成为知识依赖。
