# 使用规范记忆作为事实来源并将 Obsidian 作为视图

MyOutBrain 以紧凑、结构化、带稳定身份、来源和版本的规范记忆作为 Agent 日常调用与修订长期知识的事实来源，完整原始证据只保存一次并在整合后冷归档，Embedding、切片和索引继续保持可重建。Obsidian 不再保存唯一的永久知识，而按需投影规范记忆供创作者阅读、认知审计和提出修正；知识视图可以删除并重新生成，人工修改需要通过受控更新流程反馈到规范记忆。本决策取代 ADR-0001 和 ADR-0005 中以 Vault 知识笔记作为永久知识载体的设计。

其中“完整原始证据保存一次”的默认保留安排后来由 ADR-0054 和 ADR-0055 改为最低来源凭证与分级证据正文；规范记忆与 Obsidian 视图的边界保持有效。
