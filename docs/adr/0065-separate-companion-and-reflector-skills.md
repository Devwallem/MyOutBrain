# 分离日常同伴与反思调度 Skill

V2 使用两个共享同一本地核心接口的 Skill。`myoutbrain-companion` 作为高频轻量智能体入口，只负责任务前最小召回、任务中回答、任务后提交可见经历和任务边界信号；`myoutbrain-reflector` 只在显式反思、计划批次或待审提案场景加载，负责有界上下文采集、去重、提炼、动态编号、批量审阅和结果展示。本地核心独立持有计划、运行、统一队列、审阅批次、证据关系和规范写入状态。

## Consequences

日常任务不需要承担完整反思工作流的上下文成本，其他智能体入口也可以替换 companion 适配层而继续复用 reflector。两个 Skill 都不得直接读取数据库或把状态保存到各自目录，跨 Skill 协调只使用稳定任务、反思运行和提案身份。
