# 保留最小来源凭证并分级保存完整证据

V2 把规范记忆视为在特定时间与范围内有理由采纳的版本化理解，而不是永远正确的真理。每项长期理解必须保留足以说明来源身份、时间、采纳者、内容指纹、适用范围和必要定位或摘录的来源凭证；完整原文则依据不可替代性、风险和未来重新解释价值分级保留。用户明确确认可以由确认内容和 turn ID 支持，可重新获取的公开资料可以只保留链接、时间、哈希与必要摘录，私人原创、不可重新获取或高风险依据才默认保留完整来源。

本决策取代 ADR-0033 对完整文本对话默认永久保留一份的要求。旧知识在被新证据推翻后仍作为历史版本存在并记录当时适用范围，但来源缺失、过期或不可复核会降低其当前可回答性，不能继续伪装成有现行证据支持的事实。

## Consequences

存储增长不再由全部对话全文决定，删除和隐私要求也更容易执行；代价是重新提炼能力取决于保留级别，因此保留策略必须可审计，并在降级或删除完整证据前保留来源凭证和影响说明。
