# 仅缓冲最小反思输入包

V2 为等待批处理的普通学习信号保存临时反思输入包，只包含信号描述、相关决定或结果的必要摘录、原任务或文件等稳定引用与版本指纹，以及已知覆盖范围和上下文缺口。它不复制完整对话、代码库或工具输出；若原来源可能在执行前消失，只额外保留支撑该信号所需的最小摘录。

反思执行时必须核对来源指纹。来源已变化或不可访问时，在提案中明确标记变化和盲区，不以当前内容冒充捕获时状态。反思输入包在提案成功形成或被明确放弃后删除；长期追溯只保留提案与获批知识按照证据保留策略需要的来源凭证。

## Consequences

周批处理能够恢复关键语境，而存储不会退化为另一套完整会话归档。临时包需要过期与孤儿清理机制，删除不得破坏已经物化的提案、审计事件或知识来源闭包。
