# 通过 MCP 与 CLI 暴露记忆网关

V2 以 MemoryGateway 作为不绑定传输方式的领域契约，本地 MCP 服务作为 Skill 和智能体入口的首选结构化接口，CLI 作为通用回退、人工运维、脚本兼容和端到端验收入口。召回上下文、提交经历、启动反思、列出提案、提交审阅批次、解释记忆和追踪证据影响等操作在两种入口中共享版本化请求与响应语义；任何入口都不能绕过网关直接读取 SQLite、对象存储或 Vault。

## Consequences

本地 MCP 可以改善结构化调用、并发和能力发现，但不成为唯一可用传输。CLI 的机器格式必须保持稳定并可独立完成核心闭环，使不支持 MCP 的客户端仍能接入和验收。
