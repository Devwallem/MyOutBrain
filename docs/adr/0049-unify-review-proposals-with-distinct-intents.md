# 统一审阅提案并保留不同意图

V1 候选洞见、记忆整合提案和反思归档提案原本拥有相邻但分离的审阅生命周期。V2 使用统一的审阅提案与单一队列承载批量审阅，同时保留 `derive`、`integrate`、`archive` 和 `research` 意图及各自权限；知识、教训、技能和研究灵感只作为可丢弃的展示标签，不成为永久且唯一的记忆类型。这样可以统一交互和去重，又不会把归档操作、规范记忆变更和研究线索混为同一种写入。

## Consequences

智能体入口和 Skill 可以用稳定的提案编号组织批量审阅，但必须把批准决定交给对应意图的受控执行器。未经批准的提案不改变规范记忆或正式归档；统一队列也不能绕过既有来源、敏感度和人工审阅边界。
