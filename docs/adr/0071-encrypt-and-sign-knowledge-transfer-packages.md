# 加密并签名知识迁移包

V2 迁移包默认使用目标实例公钥加密，并由导出实例签署机器可读清单；清单包含包版本、导出与目标身份、迁移检查点以及每个对象、版本和关系的内容哈希。导入必须先验签、解密并校验完整性，任何步骤失败都直接拒绝，不能由用户忽略。密码 ZIP 只作为显式兼容模式并显示较弱保护警告；加密与签名格式采用开放、版本化且不依赖 Codex、OpenCode、Claude Code 或云厂商账户的密码套件。

## Consequences

迁移密钥由本地核心拥有并支持备份、轮换和离线恢复，不进入规范知识、客户端 Skill 或 Git。密钥轮换需要保留历史验证链，使旧包仍可验证；恢复材料必须与日常迁移包分开保管。
