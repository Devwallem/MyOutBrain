# 反证必须进入统一审阅流程

同伴在本地材料或公开检索中发现规范记忆的反例、失效声明或版本取代关系时，只把它记录为带来源的反证发现并生成 `integrate` 审阅提案，不自动改变知识状态、权重、版本或当前基线成员。反证会立即参与当前问题的可回答性判断：证据冲突未解决时不得形成无冲突结论，但这种查询级判断不等于持久语义更新。

创作者对反证提案的审阅可以修订、取代、停用旧知识或并列保留冲突；即使反证来自权威公开来源或看似机器可验证，持久处理也必须留下统一审阅决定。所谓“工单”沿用领域术语审阅提案，不另建工程事项或自动化旁路。

## Consequences

自动研究可以发现并陈述问题，却不能借验证之名取得规范知识写权限。回答服务必须能在不修改知识库的情况下组合旧知识和反证并保持未知，审阅执行器则负责之后的持久变化。
