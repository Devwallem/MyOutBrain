# 计划反思等待兼容智能体领取执行

V2 的计划任务到点时，本地核心只创建待执行反思运行、记录触发原因并冻结有界上下文范围，不自行调用模型 API。下一次 Codex、OpenCode、Claude Code 或其他兼容入口连接时，`myoutbrain-reflector` 通过稳定协议领取该运行并使用当前能力引擎完成提炼；创作者显式发起的反思则可以由当前入口立即执行。

本地核心不因计划反思保存模型提供方密钥，也不绑定某家智能体。电脑关机或没有客户端运行导致的延迟只改变执行时间，不改变已冻结输入、来源顺序和审计身份。将来可以通过单独安装并显式配置的 headless 能力引擎适配器实现无人值守处理，但它不是 V2 默认组件。

## Consequences

计划调度仍能确保工作被记录和稍后领取，同时避免后台意外网络请求、费用和客户端锁定。待执行运行需要租约、幂等领取、超时归还和版本兼容检查，多个客户端不得重复提交同一运行结果。
