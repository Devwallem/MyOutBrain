# 将文本记忆闭环作为第一阶段完整标杆

MyOutBrain 第一阶段以一个本地主要入口完成端到端文本闭环：完整对话保存一次并生成缓冲简记，回答前通过来源关系、全文检索和最小 Embedding 语义召回器同时查询共同知识基线与缓冲内容，判断知识是否足够并在必要时进行脱敏公开检索，区分内部知识、外部来源和同伴推断形成可追溯回答，再把新体会写回缓冲区，经手动、定时或强制整合更新长期知识，并能在后续模型或入口中再次召回。自然语言认知审计、纠正、停用、永久删除和分层存储报告包含在该标杆内；多入口适配器、多媒体、自主学习和完整人格系统延期，但统一记忆网关接口需要在第一阶段建立。
