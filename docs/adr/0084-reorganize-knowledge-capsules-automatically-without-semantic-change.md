# 自动执行不改变语义的知识胶囊重组

V2 允许本地核心根据容量和主题聚合度自动裂分或合并知识胶囊，无需逐次人工批准。胶囊重组只能移动规范记忆正文、调整树路由和交叉引用并更新知识字典指针，不得改写知识含义、身份、版本、可信状态或来源关系；任何可能产生语义变化的操作都必须停止重组并生成统一审阅提案。

重组采用写时复制：先生成候选胶囊，检查记录完整性、唯一主副本和指针闭包，再运行固定召回回归，最后通过原子比较并交换切换字典指针。旧胶囊保留重定向直到并发读者退出，整个过程可重复执行、可在崩溃后恢复；回归结果低于门槛时不切换或立即回滚。创作者可以固定分区、命名分区或禁止指定节点自动合并，这些约束必须跨客户端持久化。

## Consequences

容量维护不会制造日常审阅负担，也不能借维护之名改变知识。实现需要提供重组事务日志、故障注入测试、召回回归集和垃圾回收安全期；无法唯一归类的知识仍只有一个主胶囊，可以通过其他节点的交叉引用参与多主题召回。
