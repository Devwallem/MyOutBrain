# 将整个实例备份为冷 ZIP 快照

V2 备份采用整库冷快照：本地核心取得维护锁并暂停写入，提交进行中的事务、完成 WAL 检查点并干净关闭 SQLite，然后将整个主私人实例目录原样压缩为普通 ZIP，包括数据库、内容寻址对象、实例配置和审计记录；压缩完成后重新开放实例。

备份不复用增量迁移包，不执行对象可达性裁剪、增量去重、分层保留、格式转换或默认加密。恢复时把 ZIP 解压到新目录，运行 `myoutbrain doctor` 校验后再由创作者切换实例路径，不原地覆盖仍可用的数据。ZIP 的命名、保留和远程传输由创作者管理；升级或大批量导入前系统只提示备份，不自动制造备份文件。

## Consequences

备份和恢复可以用直接可理解的目录级操作完成，代价是备份体积随整个实例增长。维护锁必须有超时和失败恢复，压缩失败不得留下实例永久只读；文档需要明确禁止在核心仍写入时手工复制数据库文件。
