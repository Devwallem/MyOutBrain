# 只自动修复可重建运行数据

V2 的 `myoutbrain doctor` 默认只检查数据库一致性、对象哈希、关系闭包、胶囊约束、协议和入口配置并生成报告，不修改任何内容。创作者显式运行 `doctor --repair` 后，工具可以重建 FTS、Embedding、证据关系图投影、树摘要及其他可重建索引，并清理已证明无规范引用的临时文件、过期租约和中断胶囊重组副本。

修复不得补造缺失的规范记忆、来源对象或审计事件，不得根据剩余内容猜测知识关系、生命周期状态或创作者审阅决定。规范数据缺失、哈希不符或闭包破坏时，核心进入受限只读模式并输出修复报告；创作者可以从整库冷快照恢复，或通过另一个显式流程接受已知损失。基础设施损坏不是知识主张，不生成知识审阅提案。

## Consequences

自动修复保持确定性，不会用“看似合理”的数据掩盖真实丢失。实现必须清楚标记规范数据与可重建投影，为每个修复动作提供前后检查结果和幂等测试。
