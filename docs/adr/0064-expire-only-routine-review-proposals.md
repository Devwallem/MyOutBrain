# 只让常规审阅提案自动过期

V2 只对长期未处理的 `routine` 提案应用默认 90 天期限。过期提案退出活跃队列并压缩为指纹、主题、来源引用、形成方式和过期时间，出现实质新证据时可以恢复为新版本。`blocking`、`priority` 及创作者主动暂缓并设置复审时间的提案不按普通期限过期。已接受、编辑或拒绝的提案在结果稳定后可以压缩正文，但必须长期保留决定、最终内容、来源关系和审计；因目标版本变化失去意义的提案可以确定性标记为 `superseded`。

## Consequences

统一队列不会无限积累低价值常规建议，也不会通过 TTL 隐藏重要冲突或抹掉已作决定。调度器需要支持复审时间、提案版本和基于新证据的恢复，而不是简单删除目录中的旧文件。
