# MyOutBrain V2 发布说明

MyOutBrain V2 已具备可发布的跨入口本地知识闭环。Codex、OpenCode 与
Claude Code 的薄入口通过同一个按需启动的 V2.3 MCP/CLI 领域协议连接同一
主私人实例，共享规范记忆、统一审阅状态和紧凑召回日志。发布门禁由九项
公开黑盒场景组成，不依赖 SQLite 表、Vault 路径或客户端私有状态。

## 本次发布

- 学习信号可以经 Reflector 形成统一提案，由创作者编辑和批准后成为可召回的
  规范记忆。
- 三个智能体入口召回同一 `memory_id` 与版本，显示知识来源声明，并写入不含
  问题、正文、答案或证据正文的同构召回日志。
- 反证在当前任务内强制不可回答并进入统一审阅，待审期间不改变规范版本、
  生命周期或既有来源关系。
- 胶囊裂分、切换故障恢复与合并通过固定召回门禁，保持知识身份、正文、关系
  和公开召回结果。
- 经审计的传递知识闭包可以导出为带清单的普通 ZIP，经 dry-run 后幂等导入；
  整库冷快照只恢复到新目录，并在只读 Doctor 通过后允许切换。
- V2.0 次版本入口继续读取 V2.3 响应；无法理解准确审阅效果的入口会在写入前
  被拒绝。
- 基础闭环默认不使用 Embedding、不访问网络、也不要求常驻进程。
  `sentence-transformers` 仅属于可选的 `embeddings` 安装 extra。

运行协议为 V2.3，当前实例 Schema 为 11，迁移包格式独立保持版本 1。机器可读
操作清单与兼容规则位于
[`compatibility-v2.json`](../../src/myoutbrain/schemas/compatibility-v2.json)，请求与
响应结构分别位于同目录的 `domain-request-v2.json` 与 `domain-response-v2.json`。

## 明确非目标

V2 不提供 Embedding 模型实现或模型分发、无人值守 headless 模型调用、固定
Web/桌面/Obsidian/TUI 审阅界面、实时同步、多用户协作、内建迁移加密与签名、
设备配对、个性化知识权重、推荐算法、自动知识批准、自动反证裁决、人格与情绪
系统、多媒体理解或声音模仿。V2 也不迁移真实 V1 知识数据，不保留 V1 CLI 或
数据库布局兼容层；空实例应直接初始化为 V2。

## 后续可选能力

真实使用案例证明需要后，可以在不改变规范事实来源的前提下增加可重建的本地
Embedding 后备、显式安装的 headless 能力引擎宿主、专用审阅界面、外部加密层、
实时宿主或多设备传输。这些能力必须继续通过同一 MemoryGateway 协议协商，不能
成为基础闭环依赖，也不能把客户端缓存、向量索引或展示视图升级为规范状态。

V2 的唯一行为规格是
[`myoutbrain-v2/spec.md`](../../.scratch/myoutbrain-v2/spec.md)。V1 与第一阶段规格
保留为历史设计记录，并已明确标记为被 V2 取代；相关历史 ADR 同样保留原文及
`superseded by` 指针。
